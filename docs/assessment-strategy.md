# Assessment Strategy

## Goals

The assessment layer should:
- measure recall and reasoning for core skill areas,
- highlight weak topics for targeted re-practice,
- support short timed assessments for real-world hiring patterns,
- produce actionable feedback instead of raw marks only.

## Category coverage

- DSA: arrays, hashing, sliding window, recursion, graphs, DP.
- Aptitude: percentages, ratios, probability, time-work, speed-distance.
- Technical: SQL, APIs, system design, role-specific practice.
- Communication: grammar, speaking, email writing, HR communication.

## Scoring approach

A simple score formula is used to keep the system explainable:
- score = percentage of correct answers,
- weak topics = questions that were incorrect or skipped,
- time and recent attempts are considered during performance summaries.

This is intentionally lightweight and can be extended after agreement with the broader team.
